# Pakistan State Hub

Pakistan State Hub is a property marketplace for buying, selling, renting, and finding properties across Pakistan.

## Features

- Buy properties
- Rent properties
- Sell or list properties
- Wanted property requests
- Property search
- Property images
- Favourites
- Messages
- Notifications
- Saved searches
- Property comparison
- Reviews and ratings
- Property reports
- Admin dashboard
- Property verification
- AI-ready property features

## Technology

- Python
- Streamlit
- SQLite

## Project

Pakistan State Hub is designed to provide a simple platform for users to discover and manage residential, commercial, agricultural, and other properties across Pakistan.
